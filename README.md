# 🍔 FreshBite - Food Ordering App UX Design

![FreshBite Banner](assets/banner.png)

## 📌 Project Overview

FreshBite is a modern food ordering mobile application UI/UX design created using Figma.  
The project focuses on providing a simple, fast, and user-friendly food ordering experience.

This project was developed as part of the **Data Alcott Systems UI/UX Internship Project**.

---

## 🎯 Project Objective

The main goal of FreshBite is to design an intuitive food delivery application that helps users:

- Discover restaurants easily
- Browse food categories
- View food details
- Add items to cart
- Complete checkout process
- Track orders efficiently
